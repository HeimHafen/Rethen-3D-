# Rethen · Peiner Straße – V22 Fotoabgleich

Dies ist eine **vollständige** Browser-3D-Szene für GitHub Pages, auf Grundlage der getesteten V21-Szene. Zum Aktualisieren alle entpackten Dateien in das Wurzelverzeichnis des bestehenden Repositories übernehmen (alte gleichnamige Dateien ersetzen). `index.html`, `world.js`, `vendor/` und `assets/` werden benötigt. Keine externe Bibliotheksinstallation.

## Funktionen
- 200-m-Straßenabschnitt als gemeinsame, begehbare 3D-Szene
- zwölf auswählbare Bereiche
- beidseitige Gehwege und ein Straßenabzweig mit durchgängigen Gehwegstreifen
- Bewegung via Touch-D-Pad, Pfeiltasten oder WASD; Tag-/Nacht-Modus

## Änderungen aus den Street-View-Bildern
- Kiosk: große Holzbrüstung mit KIOSK-Schild; Metall-Rolltor; zuvor irreführendes Fachwerk auf der Giebelfront entfernt
- rötliche Pflasterstreifen an allen öffentlichen Gehwegkanten, einschließlich Bachstraße
- Backsteingiebel mit grünem Rundbogentor und zwei kleinen grünen Türen
- verfeinerte Bordsteinsituation und Schachtdeckel im Einmündungsbereich
- Baum aus der Blickachse des Abzweigs herausgenommen

## Einschränkungen
Die Umgebung bleibt eine Annäherung, **keine zentimetergenaue Rekonstruktion**. Gebäudefußabdrücke sind aus früheren Arbeitsständen übernommen. Nicht alle auf den Fotos erkennbaren Details sind bereits modelliert. Weitere Aufnahmen sollten vor der endgültigen 1:1-Abnahme systematisch nach Gebäude und Blickrichtung abgeglichen werden.
